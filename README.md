# mesharc-org/.github

This repository holds what applies across the [MeshArc](https://mesharc.dev) organisation on GitHub.

| File | What it does |
|---|---|
| [`profile/README.md`](profile/README.md) | The introduction shown on [github.com/mesharc-org](https://github.com/mesharc-org) |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability, for any MeshArc repository |
| [`SUPPORT.md`](SUPPORT.md) | Where to get help with MeshArc |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to contribute, and where each repository's own guide is |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | How we expect people to treat each other here |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) and [`PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | Issue and pull request templates for repositories that have none of their own |

GitHub uses these files for every repository in the organisation that does not have its own copy. A repository's own file always wins.

## The repositories

- [mesharc-python](https://github.com/mesharc-org/mesharc-python): Python client for the MeshArc API, with the MCP server
- [mesharc-node](https://github.com/mesharc-org/mesharc-node): Node client for the MeshArc API
- [mesharc-mcp](https://github.com/mesharc-org/mesharc-mcp): the MCP server, packaged for directories and self-run setups
