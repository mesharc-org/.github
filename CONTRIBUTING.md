# Contributing

Thanks for helping with MeshArc's open-source code. Everything here is MIT-licensed, and contributions are accepted under the same licence.

- **Each repository has its own guide** with set-up, checks and release steps: [mesharc-python](https://github.com/mesharc-org/mesharc-python/blob/main/CONTRIBUTING.md), [mesharc-node](https://github.com/mesharc-org/mesharc-node/blob/main/CONTRIBUTING.md).
- **Open an issue before a large change**, so we can agree on the approach first. Small fixes can go straight to a pull request.
- **Keep a pull request to one change**, with tests, and a changelog entry when users will notice it.
- **A new option must already work against the live API** at api.mesharc.dev. The clients follow the API; they do not lead it.
- **Never include API keys, cookies or customer data** in an issue, a test or a commit.

Security problems go to security@mesharc.dev, not to an issue: see [SECURITY.md](SECURITY.md).
