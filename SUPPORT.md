# Getting help

- **How do I…?** Start with the docs at [mesharc.dev/docs](https://mesharc.dev/docs): the API, the SDKs, the MCP server, configuration and billing.
- **Something in a client or the MCP server does not work as documented:** open an issue on that repository. Include the request id from the error if there was one, and never paste an API key.
- **Your account, billing or a crawl of yours:** write to [hello@mesharc.dev](mailto:hello@mesharc.dev). Growth plans and above get priority.
- **A security problem:** write to [security@mesharc.dev](mailto:security@mesharc.dev), not an issue. See [SECURITY.md](SECURITY.md).
- **Data protection and privacy requests:** [privacy@mesharc.dev](mailto:privacy@mesharc.dev).

We answer in working hours (India), in English.
